# Resilience Web

A directory of local groups working on social and environmental justice, organised into independent webs, one per community.

## Language

### Tagging

**Tag**:
A short label on a listing within a web, optionally shown with an icon, describing what the listing offers or is like.
_Avoid_: Label, attribute, feature

**Shared tag**:
A tag drawn from the one list common to every web, so that it means the same thing wherever it is used and can be searched across webs. A web's editors add the shared tags they want to their web; only those can go on its listings.
_Avoid_: Preset, global tag, Green Map tag

**Retired shared tag**:
A shared tag that can no longer be added to listings but stays on the listings that already have it.
_Avoid_: Deleted tag, archived tag

**Web tag**:
A tag a web's editors create for their own web, with no meaning outside it.
_Avoid_: Custom tag, local tag
